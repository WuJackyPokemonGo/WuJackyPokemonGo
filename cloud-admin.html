商品批次匯入

使用 UTF-8 CSV，每次最多 1,000 筆、2 MB。商品編號用來對應同一件商品；缺少的選填欄位保留原值，檔案內的空白會清除該欄位。新商品預設不公開，不會更動庫存。

欄位填寫說明

必要欄位為 schema_version（填 1）、sku（商品編號）、name_zh（中文名稱）。aliases 與 tag_names 使用 JSON 陣列，例如 ["異色","背景"]。日期填 YYYY-MM-DD；售價留空表示詢價。publication_status 可填 draft、published、archived；supply_status 可填 available、low_stock、sold_out、inquiry_only、coming_soon。匯出時會加上試算表安全字元前綴，重新匯入會還原。完整欄位請以範本為準。

加密備份與還原

備份包含商品、分類、庫存、採購、訂單、費用、稽核與原圖／縮圖。帳號密碼、伺服器設定及程式碼不在此應用程式備份內。手動加密檔每次可處理 16 MB 資料與 64 MB 圖片；雲端完整備份的圖片可分段補回。超過上限會停止，不會產生缺漏備份。

1. 下載加密備份

請自行設定至少 12 個字元的備份密碼，並另外妥善保存；密碼遺失無法解鎖。備份含私人交易資料，請保存在自己的裝置。

儲存加密備份檔（.wjb）

2. 從備份補回遺失資料

先解鎖、比對，再補回遺失的資料與圖片。既有內容如與備份不同，會停止整筆資料還原，避免影響後續交易。圖片逐檔補回，可使用相同備份接續重試。

使用每日完整備份／資料快照

每日完整備份含資料與原圖／縮圖，保留 30 天，可逐檔補回；匯入前資料快照只含資料及圖片索引。
