# 測試與正式發布檢查清單

所有開發只在 `test/full-build-v1` 分支進行。未取得使用者明確同意前，不合併至 `main`、不部署、不修改正式網站。

## 目前已知狀態（2026-10-17）
- `index.html`：公開商品前台初版，使用示範資料。
- `admin.html`：管理後台原型，商品新增／編輯、標籤管理、庫存異動、CSV 匯入匯出；資料只存本機瀏覽器。
- `supabase/migrations/202610170001_initial_schema_draft.sql`：資料表草稿，尚未套用至資料庫。
- 尚無正式登入、雲端同步、圖片儲存、採購來源監控或正式部署。

## A. 原型驗收
- [ ] iPhone 小螢幕與桌面版版面測試。
- [ ] 中英文、別名、圖鑑編號及前導零搜尋測試。
- [ ] 多標籤篩選、售罄商品搜尋及詢價清單測試。
- [ ] 新增／編輯商品、標籤改名／刪除、庫存異動確認。
- [ ] CSV 匯出再匯入、格式錯誤、重複 ID 與空欄位。
- [ ] 鍵盤操作、焦點、對比度、錯誤提示及無障礙檢查。

## B. 安全與資料層
- [ ] 建立外部服務前核實免費額度、休眠、備份及流量限制。
- [ ] 管理寫入功能必須先完成登入驗證與最小權限政策。
- [ ] 以匿名、一般使用者、管理員角色分別測試資料存取。
- [ ] 公開 API 僅回傳明確允許的公開欄位；供應商、成本、利潤、手續費及內部備註不得外洩。
- [ ] 庫存調整具原子性、禁止負庫存並保留操作者、時間、前後數量及原因。
- [ ] 限制圖片檔案格式與大小；制定儲存權限及保留規則。
- [ ] 金鑰不得放進前端程式碼或 Git。

## C. 雲端資料連接
- [ ] 建立資料存取層及環境設定。
- [ ] 以資料庫取代示範資料與 localStorage。
- [ ] 先在測試資料庫驗證 migration，不直接試跑正式資料。
- [ ] 加入載入、空狀態、錯誤、重試及局部失敗處理。
- [ ] 防止重複送單及多裝置同時調整庫存的競態。
- [ ] 維持先詢價、人工確認供貨與總額後才付款；不自動付款或叫貨。

## D. 訂單與財務
- [ ] 進貨批次記錄日期、數量、單位成本、來源與額外費用。
- [ ] 確認庫存成本規則；已完成交易成本需凍結。
- [ ] 平台費率可設定並保留人工調整原因。
- [ ] 分開顯示已收款與未付款訂單金額。
- [ ] 各銷售管道共用商品識別碼及庫存。
- [ ] 取消與退款使用補償紀錄，不覆蓋歷史帳務。
- [ ] 匯出商品、庫存、進貨、訂單、財務及操作紀錄。
- [ ] 匯入需先預覽、驗證重複與錯誤，再要求確認。

## E. 備份與發布
- [ ] 核實供應商實際備份能力及保留期限，不假設免費方案自動備份。
- [ ] 執行完整資料還原演練；CSV 匯出不能取代資料庫備份。
- [ ] 測試角色權限、隱私資料外洩、輸入安全、庫存邊界、手機操作及 CSV 往返。
- [ ] 完整測試詢價、人工確認、付款、採購、到貨及完成流程。
- [ ] 檢查效能、圖片壓縮、分頁、快取及資料庫索引。
- [ ] 分別準備程式碼回滾與資料庫 migration 復原方案。
- [ ] 使用者明確同意後，才合併、部署或發布正式網站。

## 上線候選版最低標準
1. 未登入者不能執行管理寫入。
2. 公開訪客無法讀取供應商及內部財務欄位。
3. 庫存不會因併發出現負數或重複扣庫存。
4. 備份已實際還原成功。
5. 手機流程及錯誤監控通過測試。
6. 正式環境變更獨立取得核准。
