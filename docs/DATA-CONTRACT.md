# 前台、後台與資料庫欄位契約（草案）

狀態：設計文件；尚未接上雲端資料庫。不要把本文件當成已部署 API 規格。

## 1. 商品欄位對照

| 概念 | 前台 `index.html` 原型 | 後台 `admin.html` 原型 | 資料庫草稿 |
|---|---|---|---|
| 唯一識別碼 | `id` | `id` | `products.id` UUID；另有 `sku` |
| 中文名稱 | `name` | `name` | `name_zh` |
| 英文名稱 | 放在 `aliases` | `aliases` | `name_en` + `aliases` |
| 圖鑑編號 | `dex` 字串 | `code` 字串 | `pokedex_number` 整數 |
| 標籤 | `tags[]` | `tags[]` | `product_categories` + `category_assignments` |
| 公開售價 | `price`；`null` 表示詢價 | `price`；空白表示詢價 | `public_price_twd` + `price_is_inquiry` |
| 庫存數量 | `stock`（示範資料） | `stock` | `inventory_balances.quantity_on_hand`（僅管理端） |
| 低庫存門檻 | 目前使用前台預設值 | `threshold` | `low_stock_threshold` |
| 供貨狀態 | `status` | 由庫存與門檻推算 | `supply_status` |
| 商品說明 | `description` | `desc` | `description_public` |

前台與後台原型目前採用不同欄位名稱及不同示範商品；這是兩份獨立原型，尚未同步資料。接雲端時應新增明確的資料轉換層，不要直接假設兩邊可互換。

## 2. 正式 API 的公開欄位白名單

公開商品端點只允許回傳必要欄位，例如：
- 商品公開 ID／SKU、中文名稱、英文名稱、公開別名、公開圖鑑編號（若決定展示）
- 公開說明、已核准的圖片 URL 與替代文字
- 公開標籤、公開售價或「私訊詢價」旗標
- 粗略供貨標籤（有庫存／低庫存／售罄／即將推出）
- 手動排序與必要的公開日期

不得回傳：
- 精確庫存（除非日後明確決定公開）
- 進貨成本、加權平均成本、供應商名稱／網址、內部備註
- 訂單、客戶聯絡方式、付款／退款資料
- 平台費、利潤、費用、稽核前後值、管理員 ID 或私有設定

安全原則：不要把私密欄位傳到前端後再用 CSS 隱藏。公開端點必須從資料來源就排除它們。

## 3. 狀態映射

| 產品狀態 | 前台顯示建議 | 後台管理原則 |
|---|---|---|
| `available` | 可詢價／有庫存 | 依庫存與門檻推算，管理員可盤點修正 |
| `low_stock` | 庫存偏低 | 低於或等於門檻時提示；不自動補貨 |
| `sold_out` | 已售罄 | 商品仍可搜尋及查看 |
| `inquiry_only` | 私訊詢價 | 不納入公開價格小計 |
| `coming_soon` | 即將推出 | 管理員手動切換，不自動接單 |

資料庫中的 `publication_status`（draft/published/archived）與 `supply_status` 是兩個不同維度：商品是否公開，不等於是否有庫存。

## 4. 庫存寫入規則

1. 前台購物／詢價清單不代表預留庫存，也不建立已確認訂單。
2. 所有正式庫存變更都應由伺服器端交易函式執行。
3. 同一個安全 RPC 交易中驗證數量、更新餘額、寫入異動紀錄與稽核紀錄；不可只更新餘額而漏掉 ledger。
4. 禁止負庫存；對多裝置並行操作採鎖定或等效的原子性策略。
5. 盤點修正、售出、退回、損壞等異動都需原因、操作者、時間及前後值。
6. 取消或退款不應刪除原始交易；以補償紀錄處理。
7. 未登入或非管理員角色不得寫入庫存、訂單、採購、成本、費用或稽核資料。
8. authenticated 管理端不得直接寫入庫存餘額／異動帳／稽核紀錄；只能呼叫經驗證的交易式 RPC，並由 RPC 完成庫存鎖定、數量檢查、異動與稽核寫入。

## 5. CSV 匯入匯出規則

目前後台 CSV 是本機原型功能，並非安全的正式資料交換流程。正式版應：
- 使用版本化欄位名稱及 UTF-8 編碼。
- 匯入前顯示新增、更新、跳過、錯誤筆數與逐列錯誤原因。
- 以穩定 SKU／外部 ID 對應，不能以商品名稱作唯一鍵。
- 明確確認庫存欄位是否允許匯入；預設不應把商品資料匯入誤當成庫存異動。
- 大量變更前產生預覽與備份；寫入失敗時避免半套更新。
- 匯出私密欄位需管理員權限並提醒保護檔案。
