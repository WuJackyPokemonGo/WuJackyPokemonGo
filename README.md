## 正式資料

沿用已驗證的 Supabase 專案 wlrwlqchlxehlvkyesnj。專案顯示名稱目前仍為 wu-jacky-pokemon-staging，但從本次發佈起作為此正式站的資料來源；請勿再新增未標記測試資料或假設此環境可清空。舊 INACTIVE 專案沒有啟用或修改。

products.is_live 預設 false。公開目錄必須同時 is_live=true 和 publication_status=published，避免先前測試商品自動公開。管理員從正式後台編輯商品，勾選「正式賣場顯示」並設定上架即可公開。

公開 API 只有 storefront_catalog，回傳白名單商品欄位，依擁有人要求顯示已確認的庫存數量與低庫存提示；不回傳庫存異動明細、成本、來源、客戶、訂單、管理員或稽核資料。匿名仍不能查基礎表或呼叫管理 RPC。

原始商品圖片保留於 private product-images。只有管理員明確選用並公開的 WebP／PNG 縮圖會複製到 public storefront-thumbnails；原圖不會上傳到 public bucket。已公開圖片的網址可能被分享或快取，取消顯示商品不會保證已公開縮圖立即失效。

supabase/production/public-storefront.sql 已透過 execute_sql 套用，沒有新增 migration history，不可重跑 schema 建置。SQL 驗收檔使用 BEGIN/ROLLBACK，不留下測試商品。

## 正式功能（2026-10-22 完整開發版）

登入後以營運報表與待辦作為首頁，商品、採購、訂單、財務、費率與排程、匯入備份分別有完整操作介面。

- 商品：中英文、別名、圖鑑號、分類、供貨狀態、原圖與縮圖、排序、上架及獨立公開開關；顧客只讀取白名單公開欄位。
- 採購：日期、供應商、數量、單價、附加費、參考與備註；可編輯或取消未到貨採購，到貨才入庫，原紀錄保留。
- 成本：到貨含附加費計算加權平均，實際商品退回按原訂單成本補回；未知成本不當成零。訂單可自動帶入平均成本，亦可明確手改。
- 訂單：網站、LINE、Facebook、Threads、8591 等來源；確認商品／成本、付款、叫貨、到貨、交付、取消與退款流程。完成交付才扣庫存，實際退款和實物退回分開記錄。
- 收退款：逐筆金額、實際日期時間、參考及原因；可分次收款、多次退款、對應原收款、超額攔截、誤記作廢、撤回未實退流程與斷線安全重試。只登錄已發生的外部交易，不替管理員轉帳或收費。
- 費率：每通路百分比、固定費、四捨五入方式及啟用開關。訂單儲存時核對費率版本，改變數量、售價或通路會清除舊費用預覽。沒有確認費率時必須手動輸入。
- 報表：台灣日期區間、交付認列營收、退款、銷貨成本、退回成本、平台費、其他成本、營運費用、估算淨利、實際收退款、應收與庫存估值；未確認資料及對帳差異獨立顯示。
- Excel：19 張工作表，包含期間報表、完整應用明細、公式與快取值；長 ID 與使用者文字保留為字串，避免當作試算表公式執行。明細可能包含報表期間外資料，檔案內已有說明。
- CSV：1,000 筆／2 MB，先預覽再確認；SKU 配對、缺省保留、空白清除、版本衝突整批拒絕；不改庫存，新商品不自動公開。
- 匿名統計：只收允許的事件與公開商品 ID、每日匿名工作階段、去重與限流；不記錄搜尋文字、客戶資料或完整 IP，訪客可停用並尊重瀏覽器隱私設定。保留 30 天，複製詢價不等同送出訂單。
- 自動備份：每 15 分鐘由伺服器檢查，台灣時間每日 03 時起執行，完整應用資料及兩個商品圖片 bucket 的物件保留 30 天；分段接續、SHA-256 校驗、狀態／重試及雲端安全補回。第一份備份已取得 HTTP 200 與 completed 回執；目前實際商品圖片數為 0。
- 手動備份：AES-256-GCM／PBKDF2-SHA256 310,000 次，管理員設定至少 12 字元密碼；17 表及圖片一同加密。密碼不送伺服器；最多 16 MB／50,000 筆資料、64 MB／10,000 圖片。
- 還原：只補回遺失資料及圖片，不覆寫後續交易；不同內容會阻擋，寫入為單一交易，庫存及收退款必須對帳。舊版 v1 支援升級：已知收退款彙總保留為 legacy，未知日期／分類不自行補填。
- Discord：已實作日報、低庫存／恢復、訂單／退款工作及備份失敗通知；採秘密保管庫、去重佇列、重試上限與停用開關。未設定通知網址，因此正式通知保持關閉，沒有發送測試訊息。

雲端每日備份與手動加密備份皆屬應用資料備份；不備份 Auth 帳號、管理員權限、API 秘密或整個供應商帳號。備份內的 schema 描述供復原參考，管理介面不會自動執行 schema。程式碼由 GitHub 保留。完整災難復原需要保留目前專案、登入方式與原始碼；手動加密檔可保存到自己的裝置。

## iPhone 圖片上傳相容性修正

2026-10-22 手機回報無法產生 WebP 縮圖。現改為優先 WebP；瀏覽器回傳 PNG、WebP 編碼拋錯或回傳 null 時，自動使用 PNG。實際檔頭決定 MIME 與副檔名，不把 PNG 偽裝成 WebP。縮圖保持比例，超過 2 MB 會逐步縮小；原始檔案位元組保留不變。

catalog-service、私人與公開縮圖路徑、公開圖片 URL 白名單、Storage MIME 及管理員限定發布政策都支援兩種格式。原圖 bucket 維持 private，僅 UUID/UUID-thumb.webp 或 .png 可公開。png-thumbnail-fallback.sql 已套用，不新增資料表／欄位，不影響既有備份或 WebP 圖片。

100 項 Node 測試通過，包含 Safari 式 PNG 回退、null／拋錯備援、真實 PNG 簽名、2 MB 縮小、原圖位元組不變、PNG 私人上傳與管理員公開。tests/png-thumbnail-acceptance.sql 回滾驗收通過：管理員可發布兩種縮圖，原圖路徑及非管理員被拒絕。擁有人重新整理正式後台、選取原圖片後驗收真實手機行為；不宣稱已在擁有人 iPhone 實機操作。版本查詢為 20261022-image-fix。
